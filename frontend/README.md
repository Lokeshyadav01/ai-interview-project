# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer built using React, FastAPI, PostgreSQL, and Google Gemini AI.

---

## ✨ Features

- 🔐 JWT Authentication
- 📄 Resume Upload (PDF/DOCX)
- 🤖 AI Resume Review (Gemini)
- 📊 ATS Score
- ✅ Matched Skills Detection
- ❌ Missing Skills Detection
- 💡 Resume Suggestions
- 📋 Resume Statistics
- 📈 ATS Breakdown
- 📱 Responsive UI
- 🖨 Download Report

---

## 🛠 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Markdown

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication
- Pydantic

- Google Gemini API

## 🚀 Installation

### Backend

```bash
cd backend

python -m venv venv

source venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
