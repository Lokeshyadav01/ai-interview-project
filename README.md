# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer that evaluates resumes against a Job Description (JD), calculates an ATS score, identifies missing skills, and generates personalized feedback using Google Gemini AI.

---

## 📌 Features

- 🔐 User Authentication (Login & Register)
- 📄 Upload Resume (PDF/DOCX)
- 🤖 AI Resume Analysis
- 📊 ATS Score Calculation
- ✅ Matched Skills Detection
- ❌ Missing Skills Detection
- 📋 Resume Suggestions
- 📝 AI-Powered Resume Review (Gemini AI)
- 📈 Dashboard
- 📜 Analysis History
- 📥 Download Resume Report
- 🎨 Modern Responsive UI

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Lokeshyadav01/ai-interview-project.git
```

```bash
cd ai-interview-project
```

---

# Backend Setup

```bash
cd backend
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate

### Windows

```bash
venv\Scripts\activate
```

### macOS/Linux

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Backend

```bash
uvicorn app.main:app --reload
```

Backend runs at

```
http://127.0.0.1:8000
```

---

# Frontend Setup

```bash
cd frontend
```

Install Packages

```bash
npm install
```

Run

```bash
npm run dev
```

Frontend runs at

```
http://localhost:5173
```
